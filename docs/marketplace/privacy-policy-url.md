### Data Privacy & Storage Highlights
- **Data Isolation**: Multi-tenant architecture with cryptographic separation between customer portals.
- **Data Ingestion**: DealSense only reads CRM deals, contacts, companies, and stage history necessary for telemetry scoring.
- **Token Security**: HubSpot OAuth access and refresh tokens are encrypted at rest using AES-256-GCM.
- **GDPR Compliance**: DealSense respects `contact.privacyDeletion` events and provides self-service deletion APIs for complete data scrubbing upon uninstallation.
- **Zero AI Model Training**: Customer CRM telemetry is never used to train generalized LLM foundation models.
