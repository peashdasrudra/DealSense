# Security Policy

## Supported Versions

We provide security updates for the current major version of DealSense.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for DealSense. We kindly ask that you practice responsible disclosure.

If you discover a security vulnerability within DealSense, please send an e-mail to our security team at **security@hubailab.com** instead of using the public issue tracker. 

All security vulnerabilities will be promptly addressed. You can expect an acknowledgment within 24 hours of submission. Once a vulnerability is verified, we will work with you to understand the severity and timeline for a patch. We will notify you when the issue has been patched and provide credit in the release notes if desired.
